Box 1: "读取当前状态 (Read current state)": 确定电梯的当前位置和状态 (Determine the elevator's current position and status)."
Box 2: "当前层要不要停 (Stop at current floor?)": 评估当前楼层是否有停靠需求 (Evaluate whether there is a stopping requirement on the current floor)."
Box 3: "停靠条件成立吗 (Are stopping conditions met?)": 确认是否有乘客请求或预设停靠点 (Confirm whether there are passenger requests or preset stopping points)."

Box 5: "保持运行 (Keep running)": 如果没有停靠需求，则继续当前方向运行 (If there is no stopping requirement, continue running in the current direction)."
Box 6: "判断前方还有没有需求 (Check if there are more requests)": 检查在当前运行方向上是否还有其他楼层有需求 (Check if there are other floors with requests in the current running direction)."
Box 7: "保持当前方向 (Maintain current direction)": 如果有需求，则保持当前运行方向 (If there is a request, maintain the current running direction)."
Box 8: "反向或待机 (Reverse or standby)": 如果没有需求，则反向运行或进入待机状态 (If there is no request, run in the opposite direction or enter standby mode)."
