=== KEY CONCEPTS ===
8 floating info boxes; each box uses a semi-transparent cloud-like blob background (marshmallow-soft, pure white at 70–80% opacity, no hard border), text in dark charcoal (#2D2D2D), medium-weight sans-serif:
Box 1: "到达某层 (Arriving at a floor)": 电梯到达了一个新的楼层。(Elevator arrives at a new floor.)
Box 2: "车内有人选了这层吗 (Did someone inside select this floor?)": 检查是否有乘客选择了该楼层。(Check if any passenger has selected the floor.)
Box 3: "停 (Stop)": 电梯在该楼层停靠。(Elevator stops at this floor.)
Box 4: "当前方向的外呼在这层吗 (Is there an external call in the current direction on this floor?)": 检查是否有与电梯当前运行方向一致的外部呼叫。(Check for external calls in the same direction as the elevator.)
Box 5: "前方已无需求且需要反向吗 (Are there no more requests ahead and a need to reverse direction?)": 判断前方是否还有未完成的请求，并且是否需要改变运行方向。(Determine if there are any pending requests ahead and if the direction needs to be changed.)
Box 6: "这层正好有反向外呼吗 (Is there a reverse direction external call on this floor?)": 检查该楼层是否有与电梯当前运行方向相反的外部呼叫。(Check if there are external calls in the opposite direction of the elevator.)
Box 7: "不停，改方向 (Don't stop, change direction)": 电梯不停止，改变运行方向。(Elevator does not stop, changes direction.)
Box 8: "不停，继续当前方向 (Don't stop, continue in the current direction)": 电梯不停止，继续沿当前方向运行。(Elevator does not stop, continues in the current direction.)
